# Commit Guidelines

Write commit messages in English and describe one focused change.

## Format

`type: short description`

## Types

- `feat`: add a feature, lab, or project
- `fix`: correct an error
- `docs`: update documentation or notes
- `test`: add or update tests
- `refactor`: reorganize without changing behavior
- `chore`: maintenance or configuration

Examples:

- `feat: add OPNsense firewall lab`
- `docs: explain Linux file permissions`
- `chore: ignore Terraform state files`
